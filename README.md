# Wave Power Solar — Storytelling Landing Page

A story-driven, modern solar-company landing page for **Wave Power Solar**, based in Varanasi, serving homeowners and businesses across Eastern Uttar Pradesh (Varanasi, Mirzapur, Chandauli, Bhadohi, Jaunpur, Ghazipur, and Prayagraj).

## 🌟 Narrative Overview (6 Chapters)

1. **Hero**: Parallax dusk solar home photography with rotating ambient sunburst SVG watermark and a floating interactive savings calculator (instant kW, yearly savings, and PM Surya Ghar subsidy).
2. **Chapter 01 (The Problem)**: The annual 44°C Purvanchal summer heat shock and rising electricity bill graph (2020–2026).
3. **Chapter 02 (The Idea)**: Dark-to-sunrise dawn gradient pivot: free, endless solar energy that never sends an electric bill.
4. **Chapter 03 (The Process)**: 4-step sticky-scroll showcase (*Talk to Us → We Visit Your Home → We Install → We Stay With You*) with alternating layout on desktop and responsive stacked fallback on mobile.
5. **Chapter 04 (The Result)**: 5,000+ happy roofs, 50+ MW installed, 25-year warranty, 4.8/5 rating + tabbed residential vs commercial paths.
6. **Chapter 05 (Their Stories)**: 3 verified Purvanchal customer stories (Sigra Varanasi, Civil Lines Prayagraj, and Bhadohi carpet belt) with before-and-after bills.
7. **Chapter 06 (Your Turn)**: Regional service matrix for Varanasi, Mirzapur, Chandauli, Bhadohi, Jaunpur, Ghazipur, and Prayagraj + free roof survey booking card.

## 🛠️ Tech Stack & Design System

- **Framework**: [Astro](https://astro.build/) (Static Output)
- **Styling**: [Tailwind CSS v4](https://tailwindcss.com/) via `@tailwindcss/vite`
- **Typography**: 
  - Headings: `Fraunces` (warm, optical-sized display serif)
  - Body & UI: `Inter` (sans-serif)
- **Brand Palette**:
  - Deep Navy: `#0F2540`, `#173257`
  - Solar Orange: `#EA6B1F`, `#F98A3D`
  - Blue: `#3E7CC9`
  - Cream: `#F7F5F0`
  - Ink: `#12233C`
- **Interactivity**: Pure vanilla JavaScript (interactive bill calculator, scroll reveals, sticky pinned scroll, accessible preloader).

## 🚀 Getting Started

### Prerequisites
- Node.js `>= 22.12.0`
- npm

### Installation
```bash
# Clone the repository
git clone https://github.com/Nilesh12-debug/wave-power-solar.git
cd wave-power-solar

# Install dependencies
npm install

# Start local dev server
npm run dev
```

The application will be available at `http://localhost:4321` (or next available port).

### Building for Production
```bash
npm run build
```
Production static assets will be output to `./dist/`.
